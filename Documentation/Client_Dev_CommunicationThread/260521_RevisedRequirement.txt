1

Solution Design

Design Document as below:
Application Architecture
High Level Architecture (Power Platform — Power Apps Code App, Power Automate, Dataverse — and the Code App's own CI/CD pipeline in Azure DevOps) and physical / cloud architecture within components in scope
Solution Intent Document
Low Level Design - UI and UX journey for requestor and approver, component design
Data Schema Definition - Dataverse table design for Requests, Software catalog, Messages, Approvals (including license-grant details), Workflow States, Audit Logs
Solution Governance Design - Define audit trail structure, logging standards, traceability design, exception-handling rules, ALM environment topology (Dev / Test / Prod) and artefact retention structure
Security & Identity Model - Entra SSO, Entra security group as the source of truth for approver role, Dataverse custom security roles for table-level authorisation, Microsoft Graph for group-membership checks
Foundation Pipeline Setup - Create baseline YAML pipeline for the Code App with stages for Code Checkout, Install + Lint + Unit Test, SBOM generation (Syft against npm dependencies), Vulnerability Scan (Grype), Build (vite), Publish (pac code push)
Post-approval Flow Design - License-grant capture on Approve, user notification with grant details, manual Installed / Install failed status progression with full audit trail

Design Document reviewed and signed off by Customer.



2

Core Development and Automation Build

Core Build and Automation as below:
Core scripts and automation logics
Form and User Interface
Power Automate Workflow
Dataverse Implementation
ADO pipeline configuration for the Code App's own CI/CD
Unit Testing Scripts (code coverage level as per Customer's deployment pipeline threshold)
Requestor Form (Power Apps Code App) - Build UI with fields for Software name, version, license type, and a combined Justification & Evidence field (rich text + multi-attachment, e.g. eProcurement URL, PO screenshot, vendor quote) with metadata auto-fill.
Approver Form (Power Apps Code App) - Build interface for license team / security reviewer including pending queue, Approve / Reject / Request more info decision panel, comments, license-grant details capture, audit log view, evidence view.
Dataverse Table Setup - Create Tables for Requests, Software catalog, Messages, Approvals (with license-grant field), Workflow States, Audit Logs.
Power Automate Workflow Build - Implement sequential approval logic, SLA timers, reminders, rejection paths, auto-escalation, More-Info auto-flip back to Pending, and user notification on Approve carrying the license-grant details.
Manual Install Status Tracking - UI actions to advance a request from Approved → Installed or Approved → Install failed, with every transition captured in the audit trail.
Audit Trail Logging Implementation - Create per-request timestamped logs for each workflow action stored in Dataverse, with Dataverse system auditing enabled on core tables as a back-stop.
Integration with Email / Teams Notifications - Configure automated notifications for request submission, approval (with license grant to the user), rejection, more-info requests, installed, install-failed, pending actions and escalations.
ADO Build Pipeline Development - Implement full YAML pipeline for the Code App with Checkout, npm ci, ESLint, tsc, unit tests, Syft SBOM, Grype vulnerability scan, vite build, and pac code push to Dev / Test / Prod.
Unit Test Coverage Build - Create Test scripts for UI validation, workflow transitions, status transitions and pipeline tasks.
CI Integration - Integrate unit tests with the Code App pipeline so pull requests and builds automatically validate coverage and critical path checks; SBOM / vulnerability scan results gate releases.
Bug Fixing & Refactoring - Resolve issues uncovered in unit testing and internal QA, ensure clean deployment to Test environment.

Build completed and deployed into Testing Environment with Customer's approval.

Acceptance Testing

Test Conditions & Cases Document (Functional Acceptance Tests)
Test Summary Report

Above two documents will include the following:
Test Plan Creation - Create end to end test plan covering functional, workflow, edge cases, negative tests and Code App pipeline execution tests.
ADO Test Cases Creation - Build detailed test cases for request submission, approval with license-grant capture, rejection, more-info loop, manual Installed / Install failed transitions, evidence upload, audit log verification and Code App pipeline execution.
Workflow Testing Execution - Execute all workflow test cases for sequential approval, escalations, SLA timers, reminders, more-info round-trip, rejection + reopen and error paths.
Pipeline Testing Execution - Validate the Code App CI/CD pipeline: SBOM generation, vulnerability scan, build, and pac code push to Dev / Test / Prod environments.
Logging & Monitoring Validation - Validate audit log completeness, timestamp precision and cross system traceability.

Test Conditions & Case Document and Test Summary Report reviewed and signed off by Customer.
